— boni-lite.glb Recomendado para juegos. Malla optimizada, mismo esqueleto y las 11 animaciones. — boni.glb Original sin optimizar, máximo detalle. Pesado para tiempo real.

¿Qué formato es?
.glb = glTF 2.0 binario, el estándar abierto para 3D en tiempo real. Un solo archivo con malla, esqueleto, animaciones y textura adentro.

Cómo se importa
· Godot 4: arrastrar el .glb al proyecto.
· Unity: paquete glTFast o UniGLTF.
· Unreal 5: File → Import (glTF nativo).
· Blender: File → Import → glTF 2.0.
· three.js / Babylon / PlayCanvas: soporte nativo.

Las animaciones vienen como clips NlaTrack.00X — los nombres legibles están en la lista de arriba.
